🎨 Cube Pattern Analysis App

A Java-based matrix analysis project demonstrating **color and pattern recognition using 2D arrays**.  
Each cube face is represented as a 7×7 matrix where **Orange = 1** and **Blue = 0**.

---

🚀 Features

- Store a 7×7 matrix (default or user input)  
- Count color blocks (total, per row, and per column)  
- Detect shapes and symmetry (vertical & horizontal)  
- Rotate patterns 90° clockwise  
- Extract submatrices of custom size  
- Perform pattern matching (3x3 patterns)  
- Replace pattern colors  
- Identify the largest connected region (DFS for blue blocks)  

---

🧠 Concepts Used

- 2D Arrays  
- Nested Loops  
- Matrix Rotation  
- DFS (Depth-First Search)  
- Pattern Matching  
- Input Validation  

---
